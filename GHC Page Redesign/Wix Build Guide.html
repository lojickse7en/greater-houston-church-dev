Greater Houston Helping Hands (GH³)

A section-by-section guide to rebuilding the redesigned page natively in Wix — chosen direction: Warm Embrace with warm earth-tone accents.

0 Strategy & legend

Build the page natively in the Wix Editor so it's responsive, editable, and lives inside your existing header & footer. Reserve embeds only for the few effects Wix can't do natively. Every item below is tagged:

Native built with standard Wix elements   CMS backed by a Wix collection (repeater)   Embed/CSS needs an HTML embed or Velo custom CSS

Don't rebuild the nav or footer. They already exist site-wide. Just add this as a new page using the current header/footer. The versions in the prototype are faithful recreations for reference only.

Spacing system

  • Content max-width 1200px, side padding 32px (20px mobile).
  • Section vertical padding ~92px desktop, 64px mobile.
  • Card corner radius 14–16px. Button radius = fully rounded (pill).
  • Team grid gap 18px; About cards gap 26px.

2 Hero — “Warm Embrace” Native Embed/CSS

Full-width Section, background Hero Navy #06273F, two columns split roughly 42% / 58%, vertically centered, ~80px top / 88px bottom padding.

  • Left column: the emblem image (logo-emblem-cut.png), max width ~360px, centered.
  • Warm glow behind emblem: place a soft radial-gradient PNG (tan, ~30% opacity) behind it, or a Wix box filled with a radial gradient rgba(200,155,106,.30) → transparent. Embed/CSS
  • Right column, stacked: a tan rule (60×4px box, #C89B6A) → eyebrow “A Ministry of Greater Houston Church” → H1 title with “(GH³)” in Light Blue → subtitle → two buttons.
  • Buttons: primary = solid Light Blue (#7FCCF7) with navy text “Request an Event”; secondary = outline Light Blue “Meet the Team”.
  • Mobile: stack to one column, emblem on top, everything centered.

Wix tip: build the “title + (GH³)” as one text element and color just the “(GH³)” span Light Blue using the inline text color picker.

3 About GH³ Native

White section. Centered eyebrow “About the Ministry” → H2 “About GH³” → 54px tan rule. Below, a two-column row of cards (stack on mobile):

  • Each card: background Hero Navy #06273F, radius 16px, padding ~38px, a 5px tan bar down the left edge.
  • Card content: small Light-Blue label (OUR MISSION / OUR VISION) → bold white title → paragraph (use the exact mission/vision copy from the current site).

4 Our Team CMS Native

Navy band (#002339). Centered eyebrow + “Our Team” + tan rule, then a Repeater.

Create a CMS collection: HelpingHandsTeam

Bind a 4-up repeater (2-up tablet, 1-up mobile) to the collection, sorted by order. Card item: name (white, 18px/700) → role (Light Blue, uppercase 11.5px/700) → email (white 58% opacity, links to mailto:).

  • Use a filtered repeater per group (or three datasets) to reproduce the three blocks: Our Team (Regional, 4-up), Our Team With HOPE Worldwide (HOPE, 2-up), Support Team (Support, 2-up). Each sub-block has a left-aligned heading with a thin divider line.
  • Card hover (lift + tan top-border): Wix gives you a built-in hover state for the box (slight move + shadow). The animated tan top-line is the one flourish that needs Embed/CSS — optional; the hover lift alone looks great.

Why CMS: reps change. With a collection, adding or editing a team member is a content edit — no design work, no risk of breaking layout.

5 Community Service CTA Native

White section, centered. Church line-icon (74px, navy) → H2 “Have a Community Service Event?” → paragraph (existing copy) → solid navy pill button “Make a Request” linking to the request form / footer. Use a Wix vector/icon for the church, or export the one in the prototype as SVG.

6 Decorative flourishes Embed/CSS

  • Skyline line-art (only used in the “Skyline” direction — skip for Warm Embrace).
  • Faint arc texture behind the team band: optional. Use a low-opacity PNG positioned left, or omit.
  • Reveal-on-scroll: apply Wix’s built-in Fade in / Float up animation to the hero text, cards, and headings — no code needed. Keep it subtle.

7 Build checklist

  • Add the 8 palette colors + upload Proxima Nova; set the text styles in the table.
  • New page using existing header/footer.
  • Hero section: split layout, emblem + warm glow, tan rule, title, two buttons.
  • About: 2 navy cards with tan left-bar on white.
  • Create HelpingHandsTeam CMS collection; import the 12 members.
  • Team band: three group-filtered repeaters (4-up / 2-up / 2-up).
  • CTA: church icon, heading, copy, navy pill button.
  • Apply built-in fade/float-up reveal animations.
  • Add optional Embed/CSS flourishes (card top-line, glow) if desired.
  • QA at 1440px and 390px; check email links, button links, form.
